- `losat psiblast` takes `-searchsp` and reads the environment variable `OLD_FSC` (any value, an empty one too), as NCBI BLAST+ 2.17.0 does, byte for byte, with `-subject` or `-db`, FASTA queries and `-in_pssm`, in one round and in rounds: NCBI then has no Gumbel block in any round, so every round's hit cutoff is `BLAST_Cutoffs`' and every E-value (the preliminary ones, the traceback's and the position-based redo's) Karlin-Altschul's simple form on the round's effective search space (the `-searchsp` value, or the computed space for `-searchsp 0` and `OLD_FSC`); the alignments a round includes, the number of rounds, convergence and the PSSM files follow those E-values, and the outfmt 0 footers print `Lambda K H` without `a alpha sigma`. Before, psiblast's parser refused `-searchsp` and psiblast refused `OLD_FSC` (`rpsblast` still refuses both). Without the Gumbel block a `-subject` set of fewer letters than sequences now ends `blastp` and `psiblast` with NCBI's `BLAST engine error: The average subject length is too short` (exit status 3) after the subjects' warnings and the outfmt 0 prolog, where LOSAT's blastp refused it; after a first query batch that NCBI does not search (queries without Karlin-Altschul parameters), blastp now writes that batch's report before the error, as NCBI does, for this error and for a database without sequences (outfmt 0, 6, 7 and 10), and a run of such queries only against a database without sequences gives NCBI's reports (exit status 0) where LOSAT refused it. A hit cutoff whose `K × searchsp / E` is past the double range (an E-value near 1e-297 with a search space above about 4e12, or the largest `-searchsp`) was taken as 2,147,483,647 and dropped every hit; it is now the finite `(ln K + ln searchsp − ln E) / Lambda` rounded up, so such searches report their alignments as NCBI 2.17.0 does (NCBI's own conversion there is undefined behaviour of its C code), in the cutoff that blastp, blastx, tblastn, tblastx and psiblast share. `psiblast -in_pssm` refuses a PSSM with a negative Karlin-Altschul value, with which NCBI goes on with a block it holds invalid (line PS, item PS5c; DECISIONS 19, 23 and 28).
