# The FASTA reader of dustmasker and segmasker (CMaskFastaReader)

`cases.tsv` lists the cases; `ncbi/` holds the output of each from NCBI BLAST+ 2.17.0 `dustmasker` and `segmasker`.

`in/`: the inputs made by `gen.py` and `gen2.py` of the probe of ad-RG-K-1 (scripts kept with that session's files, not in
this repository), added with commit 44225f350 (2026-11-13). No source of the letters is recorded.
