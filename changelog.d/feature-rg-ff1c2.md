- `-export_search_strategy -` writes the search strategy to the standard output as NCBI BLAST+ does, in all eight search programs: each request goes into the report ahead of its batch's results when the report is on the standard output too, and the requests alone are on the standard output with `-out`. LOSAT Web and the library API still refuse `-`.
- A run whose report cannot be written (`-out /dev/full`, a file at its size limit) no longer writes the search strategy requests of the query batches after the one whose report failed: `-export_search_strategy` (a file, `/dev/stdout` or `-`) ends with the requests NCBI BLAST+ 2.17.0 wrote before its run stopped. Before, `blastp`, `tblastn` and the other programs that read several batches ahead added the next batches' requests.
- `psiblast` with `-in_pssm` or `-in_msa` and rounds (`-num_iterations` other than 1, `-out_pssm`) writes its report's prolog before the search strategy request, as NCBI does: with `-export_search_strategy -` or `/dev/stdout` the request no longer comes before the prolog.
