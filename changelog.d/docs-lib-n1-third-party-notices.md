- Third-party notices: `THIRD_PARTY_NOTICES` gives the notices of the code in LOSAT's source that
  comes from other projects (LMDB, Boost, Arm Optimized Routines, Sun's fdlibm, Microsoft's C
  runtime, the Rust crates bzip2 and ruzstd) and NCBI's public domain notice, and
  `THIRD_PARTY_LICENSES` the licenses of the Rust crates, the Rust standard library and wasi-libc
  that the binaries link. The release archives, the crate (notices), the pylosat wheel and sdist
  and the npm package carry them; the License sections of the READMEs and the manual say which
  code is NCBI's and which is LOSAT's own.
