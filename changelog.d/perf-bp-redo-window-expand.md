- `blastp` with more than one thread expands its compact preliminary hit lists as the windows of the redo reach them instead of all before the redo, so it holds the expanded lists of about one window (`LOSAT_X_BPREDOWINEXPAND`, one of the switches of the strict set, so the output does not change; `LOSAT_X_BPREDOWINEXPAND=0` turns it off; `LOSAT_X_BPREDOWINEXPANDSHADOW=1` also expands every list first and compares the windows and the lists) ([`docs/agents/diagnostics.md`](docs/agents/diagnostics.md)).
