# Independent TBLASTX data-movement source audit

User requested the same stable-data optimization for TLOSATX, with BLASTP qualification first. Reviewer: `ncbi_parity_auditor` (`/root/audit_megablast`), read-only, 2026-09-13. Related production files match B1. No performance measurement or implementation was performed in this audit.

The primary candidate boundary is `ungapped_hit_sort.rs:43–48`: each sort clones N full records into a temporary vector, sorts indices, then clones N records back. Linking calls this helper three times (`sum_stats_linking/linking.rs:588,774–775`), for6N logical record copies per linking call. Frame-group distribution/recombination adds about2N ownership transfers, and final replay clones R records at849. NCBI `blast_hits.c:1379–1381` and `link_hsps.c:476–486,990–994,1081` sort/replay HSP pointers while retaining their payloads.

Both preliminary and post-reevaluation linking calls at `run_impl.rs:2305,2465` are required by NCBI `blast_engine.c:870–899,1492–1520`; neither may be removed. The inner linking owner already uses a fixed `pool_hsp_links` arena and index-based intrusive lists (`linking.rs:1061–1101,1948`), so it does not repeatedly shift all HSPs on every selection.

Secondary payload boundaries are incoming retain/append/conditional score sort in `run_impl.rs:490`, frame aggregation around2249, and reevaluation survivor push/sort in `blast_engine/mod.rs:226–357`. NCBI compacts/merges pointer arrays (`blast_hits.c:2687–2734,2758–2766,2991–3031`). Sorting chunk result vectors or sending them through a channel moves vector headers, not all payloads. Endpoint purge is not called by the normal TBLASTX path, and culling/dump-only clones must not be attributed to ordinary inputs.

A bounded future candidate can retain fixed HSP storage throughout linking, using handles for the three sorts, frame grouping and chain replay, then materialize once. It must preserve comparator ties, reverse→forward sort order, group-index parallel reduction, every chain member, link IDs and replay order. Replay-index uniqueness requires checking before replacing clones with ownership takes. Measure call counts, record size, bytes and boundary time first; source-level copy counts are not measured memory traffic or a speed result. Existing LC threshold and long gencode4 fixtures remain regressions; no resolved parity issue is reopened.
