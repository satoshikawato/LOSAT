- blastn now writes BLAST XML, XML2 and JSON (`-outfmt 5`, `13` to `16`) one query batch at a time, as NCBI BLAST+ 2.17.0 does, instead of holding every report until the search ends; so the hit lists and reports of earlier query batches are no longer kept, and the reports do not change. Where LOSAT refuses a title of punctuation alone (on which NCBI crashes), the reports before it now come first: for `-outfmt 5` those of the query batches before, as for the other formats; with `-subject` and `-outfmt 13` to `16` those of the queries before it, which NCBI writes before it crashes. A refused first report still writes nothing.
