- `blastp -use_sw_tback` now runs with composition-based statistics (`-comp_based_stats` 1, 2 and 3; 2 is the default), where LOSAT refused the option before: each match is aligned again with NCBI BLAST+ 2.17.0's Smith-Waterman traceback on the composition-adjusted matrix, at every `-num_threads` as NCBI's `-num_threads 1` does it. A query batch whose last Smith-Waterman alignment fails ends as NCBI's does when the batch's first query has kept no alignment: the results of the query batches before, then `LOSAT engine error: Traceback failed`. Still refused: `-use_sw_tback` without composition-based statistics in `blastp` (`-comp_based_stats 0`, and `-matrix IDENTITY`, which NCBI searches without them), in `blastx`, `tblastn` and `psiblast`, a query and subject whose alignment NCBI never finishes, and a query batch on which NCBI crashes, one whose last alignment fails after the batch's first query has kept one; both come after the results of the query batches before, which NCBI prints before it searches that batch (the manual's page "What LOSAT refuses"). `blastp`'s refusals of a query chunk that NCBI would split again or that holds no query (`CHUNK_SIZE`, `OVERLAP_CHUNK_SIZE`, also with a negative `CHUNK_SIZE`) come after the results of the query batches before as well, and so does the refusal of a negative pair whose chunks leave gaps between them (which NCBI searches without the hits in the gaps).
