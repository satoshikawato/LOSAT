- `tblastx -word_size 2` and `4` (NCBI BLAST+ 2.17.0 takes 2 to 4; LOSAT refused every word size but 3), with every `-matrix`, `-threshold` and `-window_size`, `-subject` and `-db`: the search builds NCBI's lookup table of that word length and runs the reference frame loop and the reference two-hit extension, whose loop over the word reads the length. Output equals NCBI's at 1, 4 and 8 threads. The default search (BLOSUM62, word size 3) runs the code it ran before (callgrind instructions at one thread x0.99995 and x1.00004). The LOSAT Web form offers NCBI's TBLASTX word sizes 2 and 3 (4 after "Other").
