- BLASTP, BLASTX, TBLASTN, TBLASTX and PSI-BLAST: a search whose protein lookup table holds 2^31 or more overflow entries (about 8 GiB, for example TBLASTX with one 60 kb query and `-threshold 3e9`, or TBLASTN with a raised `BATCH_SIZE`) now runs, where it crashed with a segmentation fault (NCBI BLAST+ 2.17.0 crashes on the same inputs). The multi-thread table builds no longer stop at that size. Smaller tables are built byte for byte as before, so their output is unchanged.
