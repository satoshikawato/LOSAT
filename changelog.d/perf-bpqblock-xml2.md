- `blastp` searches its queries in blocks of whole query batches also when the report is `-outfmt 15` or `16` (`LOSAT_X_BPQBLOCKXML2`), as it does for `-outfmt 5`: a large query set needs the memory of `-outfmt 6` instead of that of the search of all queries, with the same report bytes. A run whose block search could refuse after some blocks' bytes (a name that NCBI cannot write as for `-outfmt 5`, a `-db` sequence whose taxid does not read, a taxonomy database that does not open or whose name of a taxid NCBI cannot write) takes the search of all queries. `=0` or `LOSAT_X_DEFAULT=0` turns it off.
