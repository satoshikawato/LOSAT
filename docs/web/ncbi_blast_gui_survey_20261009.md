# NCBI BLAST のウェブ画面の下調べ（2026-10-09）

S13 の最中に保守者が「次のセッションで NCBI BLAST ウェブサイトの GUI にデザインを寄せてほしい」と指示した（2026-10-09）。その段階 S13b（W4b、[指示書](../losat_web_gui_sessions/session_s13b_w4b_ncbi_style_ui.md)）のための下調べで、S13 の agent が書いた（英語）。HTML・CSS・JS は取得したが描画はしていない。公開の配列 NM_000518.5 と NM_000519.4 の blastn の 2 配列の検索を 1 件、NCBI で実行した（RID CHTYGRST114）。S13b は描画した画面で確かめ直す（下の 4.）。


Evidence tags: [LIVE-HTML] = fetched live page HTML/CSS/JS from blast.ncbi.nlm.nih.gov with curl (no browser, no rendering);

## 1. Search page  (Blast.cgi?PROGRAM=blastn&PAGE_TYPE=BlastSearch...)  [LIVE-HTML]
Top: gov banner, "Log in", breadcrumb "BLAST(R) >> blastn suite", links Home | Recent Results | Saved Strategies | Help.
Page title (div.pageTitle): "Standard Nucleotide BLAST" (blastp "Standard Protein BLAST"; tblastn "Translated BLAST: tblastn"; tblastx "Translated BLAST: tblastx"; bl2seq blastn "Align Sequences Nucleotide BLAST").
Program tabs (5 buttons, lower-case): blastn | blastp | blastx | tblastn | tblastx (current = tab-current). Tab keeps BLAST_SPEC (bl2seq stays on when switching).
Under tabs: one-line program description (e.g. "BLASTN programs search nucleotide databases using a nucleotide query. more..."; bl2seq: "...search nucleotide subjects using a nucleotide query."), then two small secondary buttons "Reset page" and "Bookmark".
Sections are <fieldset><legend> boxes, in this order:
1. "Enter Query Sequence"
   - label "Enter accession number(s), gi(s), or FASTA sequence(s)" + help "?" toggler + link "Clear"; textarea (name QUERY, 5 rows x 80 cols).
   - "Query subrange" (help) with two text inputs, labelled "From" and "To" (QUERY_FROM, QUERY_TO); help text: coordinates 1..length.
   - "Or, upload file": <input type=file> (single sequence or list) + help.
   - "Genetic code" select (shown only for blastx/tblastx query; 24 entries "Standard (1)", "Vertebrate Mitochondrial (2)", ... default Standard (1)).
2. "Job Title": one-line text input; help "This title appears on all BLAST results and saved searches." (auto-filled from the first query defline).
3. Checkbox "Align two or more sequences" (+ help). Ticking it RELOADS the page with BLAST_SPEC=blast2seq (keeps typed text if <=1500 chars); form action becomes BlastAlign.cgi.
   With it ticked, CSS body.blast2seq: shows fieldset "Enter Subject Sequence" (after the checkbox), HIDES "Choose Search Set" (#choosedb) and PSI/PHI/DELTA/kmer parts.
4. (bl2seq only) "Enter Subject Sequence": label "Enter accession number(s), gi(s), or FASTA sequence(s)" + help + "Clear"; textarea (SUBJECTS, can hold several FASTA records); "Subject subrange" From/To; "Or, upload file" (SUBJECTFILE). Mirrors the query block.
5. "Choose Search Set" (database search only; absent in bl2seq): "Database" radio row (Standard databases (nr etc.): / rRNA/ITS databases / Genomic + transcript databases / Betacoronavirus / Experimental databases) + database select; "Limit by" radios (Organism / BioProjectID / WGS Project, only for WGS); "Organism" Optional autocomplete text + "exclude" checkbox + "Add organism"; "Exclude" Optional: "Exclude Models (XM/XP)", "Exclude Uncultured/environmental sample sequences"; "Limit to" Optional: "Sequences from type material"; "Entrez Query" Optional text. (blastp adds "Non-redundant RefSeq proteins (WP)".)
6. "Program Selection"
   - blastn: "Optimize for" radios: "Highly similar sequences (megablast)" (default for db search) / "More dissimilar sequences (discontiguous megablast)" / "Somewhat similar sequences (blastn)" (default in bl2seq); help line "Choose a BLAST algorithm".
   - blastp: "Algorithm" radios Quick BLASTP / blastp / PSI-BLAST / PHI-BLAST (+pattern box) / DELTA-BLAST (default blastp; PSI/PHI/DELTA/Quick hidden in bl2seq). tblastn/tblastx: no choice (section hidden).
7. Primary button "BLAST" (blue, usa-button) followed on the same line by the text "Search using Megablast (Optimize for highly similar sequences)" (text follows program: "Search using Blastp (protein-protein BLAST)", "Search using Tblastn (search translated nucleotide databases using a protein query)", "Search using Tblastx (...)"), then checkbox "Show results in a new window". The whole block is repeated at the page bottom (second BLAST button, id nw2).
8. "Algorithm parameters" = a collapsed accordion button (arrow); inside, a note "Parameter values that differ from the default are highlighted in yellow and marked with ♦ sign" and link/button "Restore default search parameters". Sub-fieldsets in order (each field: label, control, ♦ marker, "?" help with "more..." link):
   - "General Parameters": "Max target sequences" select 10/50/100/250/500/1000/5000 (default 100; help "Select the maximum number of aligned sequences to display"); "Short queries" checkbox "Automatically adjust parameters for short input sequences" (default on; blastn/blastp); "Expect threshold" text (default 0.05, in bl2seq run also 0.05); "Word size" select (megablast 16,20,24,28*,32,48,64; blastn 7,11*,15; disco 11,12; blastp/tblastn 2,3,5*,6; tblastx 3 default); "Max matches in a query range" text (0; blastn only).
   - "Scoring Parameters": "Match/Mismatch Scores" select (1,-2*; 1,-3; 1,-4; 2,-3; 4,-5; 1,-1) [blastn]; "Matrix" select (PAM30, PAM70, BLOSUM90, BLOSUM80, BLOSUM62*, BLOSUM50, BLOSUM45, PAM250) [protein programs]; "Gap Costs" select ("Linear" or "Existence: 5 Extension: 2" ...; options depend on score/matrix; protein default Existence 11 Extension 1); "Compositional adjustments" select (No adjustment / Composition-based statistics / Conditional compositional score matrix adjustment / Universal compositional score matrix adjustment) [blastp, tblastn].
   - "Filters and Masking": "Filter" -> checkbox "Low complexity regions filter" (default on for protein); checkbox "Species-specific repeats filter for:" + big select of species (megablast only); "Mask" -> checkbox "Mask for lookup table only" (default on blastn), checkbox "Mask lower case letters".
   - "Discontiguous Word Options": "Template length" (None/16/18/21), "Template type" (Coding/Maximal/Two templates) [disco only]; "PSI/PHI/DELTA BLAST": PSSM upload, thresholds, pseudocount [hidden in bl2seq].
Footer: gov/NLM footer (omit).
Not verified: exact rendered look of the collapsed accordion, which parameter groups JS hides per program (inferred from option lists and CSS classes).

## 3. Visual conventions  [CSS + DOC-IMG]
- Fonts: Source Sans Pro / Helvetica Neue / Roboto / Arial sans-serif (USWDS/NCBI "nwds"); legacy search page body is arial,tahoma,verdana at 83% size (about 13px); results use ~14-16px, bold labels. Alignments in monospace.
- Colours: links blue underlined (#369 legacy; #0071bc new; hover #205493 / #069; visited #664E99); primary buttons and active tabs #0071bc with white text; legend/section headings on the search page teal-blue #369 inside a 1px #ccc border fieldset with a light-grey #ddd legend box; page background white; results toolbars pale teal (#bcd9d6 / #dcf1ee), table header pale blue #e1f3f8, panel background #f1f1f1; selected-row/active highlight #9BDAEF; non-default parameter = yellow (#ffc) with the diamond marker; message colours: error #fbb/#c00, warning #ffc, ok #dfd/#060, info #ace. "Related Information" heading dark red.
- Density: compact; form width min 850px (form.f-wrap-1 min-width:850px), labels left, controls inline; help text hidden behind "?" icons that toggle a bordered pale-blue helpbox (#def) with "more..." link.
- Collapse/expand: help = toggler "?" opens inline helpbox; "Algorithm parameters", "Citation", "See details", "Search Summary", taxonomy tree and Download/Select columns are collapsible (USWDS accordion / popovers); results tabs are accordion buttons.
- Narrow screens: search page has no real responsive layout (fixed min-width 850px; only #adVDiv rule at max-width 1175px); results CSS has @media breakpoints at 481/600/1201/1250 px (filter panel width, range inputs). No separate mobile design found; not verified in a rendered viewport.
