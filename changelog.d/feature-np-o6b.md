- `losat blastp`, `losat psiblast`, `losat tblastn` and `losat tblastx` take `-subject_besthit`, as NCBI BLAST+ 2.17.0 does, with `-subject` and `-db`: of the alignments of a subject, only the best one is kept for each part of the query (a later one whose query range lies within a kept one's, widened by 3 letters on each side, is removed), both where NCBI filters the preliminary results and after the final alignments. LOSAT Web shows the option as "Subject best hit" for these programs, and `pylosat.Search` takes `subject_besthit` for them. BLASTN and BLASTX give the same output as before.
