- `blastp` with a query batch that it splits into pieces (a batch of 19,800 letters or more with the default `CHUNK_SIZE`, such as a titin, or any batch past a smaller `CHUNK_SIZE`) no longer puts that batch's queries into the lookup table of the whole search, whose results for them the pieces' searches replace: as in NCBI BLAST+ 2.17.0, which builds no table for such a batch, only the pieces' own tables hold their words. Results are unchanged.
