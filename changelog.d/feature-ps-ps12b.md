- `losat rpstblastn` runs NCBI's default composition-based statistics (`-comp_based_stats 1`) and modes 2 and 3, so a plain `losat rpstblastn -db CDD -query genes.fna` now gives the hits, scores, e-values and reports of NCBI BLAST+ 2.17.0 `rpstblastn`, byte for byte at every thread count (apart from the version line, which names LOSAT): each profile's matches are redone in the windows of each frame with the scores adjusted to the profile's composition (the `.freq` file; NCBI's error when it is missing), with `-strand plus` or `minus`, `-query_loc`, `-searchsp`, `-dbsize`, `OLD_FSC`, the masks and outfmt 0 to 4, 6, 7 and 10. Before, only `-comp_based_stats 0` ran. `-use_sw_tback` with composition-based statistics stays refused until a later item (line PS, series PR, item PS12b; DECISIONS 38, 63 and 69).
