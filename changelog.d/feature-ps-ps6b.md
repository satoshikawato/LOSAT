- `losat psiblast -in_msa` reads alignments in FASTA (with gaps), PHYLIP, NEXUS, Sequin and MultAlin format as well as Clustal: the format is found from the first lines of the file as NCBI BLAST+ 2.17.0 does, and the rows, the errors for a file that cannot be read and the exit status are NCBI's. The text after a sequence's name is its title (the `# Query:` line, the PSSM file, the messages), with its `[name=value]` modifiers read as NCBI reads them: the same warnings for a modifier it does not know or discourages, the same error for a value it rejects (PS6b; DECISIONS 74 of line PS). Where NCBI crashes or reads memory the file does not give (a PHYLIP header of 0 sequences, an empty NEXUS command, FASTA rows of different lengths read past their end, a `secondary-accession` modifier, a `molecule` or `mol-type` modifier that makes the query a nucleotide sequence), LOSAT stops with a message that says so; a modifier that sets more than the title of the query is refused only where the run writes the query with its descriptors (`-out_pssm` without `-save_pssm_after_last_round`, `-save_each_pssm`, `-export_search_strategy`).
