- `blastn -task dc-megablast` searches of several query batches whose lookup tables are laid out as CSR (large query sets) build each batch's table faster: it reuses the previous batch's list of query offsets instead of mapping and faulting in that memory again (dmel cDNAs, 31,168 queries, against 3 Mb of the dmel genome: x0.946 of the time at 16 threads, x0.962 at 8 and x0.986 at one, peak memory +0.5 % or less) (`LOSAT_X_CSRQSKEEP`, a switch of the strict set, so reports do not change; `=0` turns it off) ([`docs/agents/diagnostics.md`](docs/agents/diagnostics.md)).
