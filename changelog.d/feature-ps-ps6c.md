- `losat psiblast -outfmt 0` with a PSSM query of the molecule `other` (`-in_msa` with a `molecule=other` or `mol-type=other` modifier, or an `-in_pssm` file whose Seq-inst is `other`) writes the whole report as NCBI BLAST+ 2.17.0 does instead of refusing it: the query is searched as a protein, and each alignment is replaced by the line `Sequence with id <id> no longer exists in database...alignment skipped`, one for each HSP, with no subject heading and no score lines (NCBI's alignment display cannot read the query's letters). The id is the subject's own; `BL_ORD_ID:<oid>` for a database sequence without ids; `Subject_N` for the N-th `-subject` record (PS6c).
