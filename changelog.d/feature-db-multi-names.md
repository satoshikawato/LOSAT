- `-db` names several databases as NCBI BLAST+ reads it (`-db "a b"`, `-db '"a b" c'`): `blastn`, `blastp`, `blastx`, `tblastn`, `tblastx` and `psiblast` search them as one database, with NCBI's ordinal ids (volumes in NCBI's order whatever the order of the names), statistics and reports (the outfmt 0 header joins the titles with `; ` and sums the counts, the epilog has one block per name, XML2 and JSON name each database). Refused: a list that reaches a volume through an alias file and again, and a version 5 list that mixes databases with and without the accession table of `makeblastdb -parse_seqids` (NCBI stops at its reports when a hit has a parsed Seq-id). Two databases of one base name in different directories are read. `losat blastdbcmd` keeps one database. `blastn -outfmt 11` records the `-db` value without white space at its ends, as the other programs do.
