# Range NV: TBLASTN and TBLASTX options layer, task defaults and NCBI's option checks

Files to write: `NV.tsv`, `NV_notes.md`. Scratch: `scratch_NV/`.

Entry points (NCBI): `CBlastOptionsFactory::CreateTask` for tblastn, tblastn-fast, tblastx (`src/algo/blast/api/blast_options_handle.cpp`), `CTBlastnOptionsHandle` (`src/algo/blast/api/tblastn_options.cpp`: defaults incl. comp-based stats, sum stats, intron length, X-drops, matrix, gaps, word size, threshold for tblastn-fast), `CTBlastxOptionsHandle` (`tblastx_options.cpp`), the arg handlers in `src/algo/blast/blastinput/blast_args.cpp` that override them (CGenericSearchArgs with `-matrix` (`BLAST_GetProteinGapExistenceExtendParams`, `BLAST_GetSuggestedThreshold`, `BLAST_GetSuggestedWindowSize`), CCompositionBasedStatsArgs (tblastn values), CGappedArgs (`-ungapped`), CLargestIntronSizeArgs, `-xdrop_gap`, `-xdrop_gap_final`, `-sum_stats`, CGeneticCodeArgs, CFilteringArgs (`-seg`, `-lcase_masking`, `-soft_masking`), tblastx `-culling_limit` via CHspFilteringArgs), `CBlastOptions::Validate` -> `BLAST_ValidateOptions` (`src/algo/blast/core/blast_options.c`, all sub-validators with their tblastn/tblastx branches: matrix/gap table, word size range, threshold, window, intron length, ungapped + sum stats, culling limit, evalue), `BlastFilteringOptionsFromString`, and the order, texts and exit codes of the errors.

LOSAT counterpart: `algorithm/tblastn/args.rs` (`validate`, `search_settings`, `effective_threshold`, `effective_window_size`), `algorithm/tblastn/scoring.rs` (`matrix_params`, `suggested_threshold` (note: it returns raw + 2.0; check against NCBI), `suggested_window_size`), `algorithm/tblastx/args.rs`, `blastinput/value_parsers.rs` (`tblastx_word_size`, `tblastn_*`), `algorithm/tblastx/blast_engine/run_impl.rs` (checks in `run`). One row per option x value class (each matrix name for tblastn, gap pairs in/out of table, threshold 0/real/large, word size per program and lookup, window 0, comp_based_stats spellings for tblastn, sum_stats false with/without ungapped, max_intron_length values, xdrop values, culling limit, seg forms, gencode IDs) and per task default. Run both binaries to confirm.
