- `losat psiblast` runs the rounds of FASTA queries as NCBI BLAST+ 2.17.0 does, byte for byte, with `-subject` or `-db` and outfmt 0, 6, 7, 10 and 20 (custom fields too): `-num_iterations N` (0: until convergence) searches each query again with the PSSM that NCBI's PSSM engine makes from the round before (its Seq-aligns below `-inclusion_ethresh`, the round's Karlin-Altschul blocks, `-pseudocount`), one query at a time, and stops as NCBI's `CPsiBlastIterationState` does (a round without hits; the subjects below the threshold all found in the round before, with `Search has CONVERGED!`; N rounds). A later round's report has `Results from round N`, its description table in NCBI's two parts ("Sequences used in model and found again", "Sequences not found previously or not previously below threshold"; the parts count Seq-aligns up to `-num_descriptions`, each with its own column widths) and the PSSM's Karlin-Altschul values in its footer; outfmt 7 shows `# Iteration: N` and counts the rounds in `# BLAST processed N queries`. The default composition-based statistics run as 1 in the PSSM rounds, with NCBI's warning once per query; `-comp_based_stats 0` is taken (round 1 with blastp's ordinary traceback and psiblast's hit list size). `-out_pssm` and `-out_ascii_pssm` (with the four Karlin-Altschul blocks of the round's ancillary data) are written at the start of each later round, with `-save_each_pssm` as `F.1`, `F.2`, ... over the whole run, and with `-save_pssm_after_last_round` after the last round (also after a round without hits); an `-out_pssm` file that cannot be written stops the run after the report of the round before (LOSAT's refusal where NCBI writes its serial-stream error), an `-out_ascii_pssm` file that cannot be opened is ignored as NCBI ignores it. Refused with more than one round: `-query_loc` (NCBI's later rounds align the PSSM of the whole record to the range), `-seg` and `-soft_masking true`, a query that NCBI splits into chunks, `-in_pssm` (item PS5b), and `-num_iterations` other than 1 in the library API and pylosat (line PS, item PS5a; DECISIONS 15).
