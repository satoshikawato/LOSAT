- BLASTP, BLASTX, TBLASTN, TBLASTX and PSI-BLAST: a protein lookup table of 2^31 or more overflow entries (about 8 GiB; for example TBLASTX with one 60 kb query and `-threshold 3e9`, whose `Int4` `INT_MIN` makes every word a neighbor of every position, or TBLASTN with a raised `BATCH_SIZE`) no longer crashes the search (segmentation fault) or reads outside the table: a cell's overflow cursor holds any position of the array, where NCBI's `Int4` cursor overflows (NCBI BLAST+ 2.17.0 crashes on the same inputs). The parallel table builds no longer stop at 2^31 entries. Tables below that size are byte for byte the same, so the output is unchanged.
