- Changed `losat makeblastdb`: it writes format version 5 by default, as NCBI makeblastdb does (`-blastdb_version 4` writes the older layout). A version 5 database has the LMDB files of its volumes (`.pdb`, `.ptf`, `.pot`, `.pto`; `.ndb`, `.ntf`, `.not`, `.nto`), written page for page as makeblastdb writes them, with their tax-id table (tax id 0 for every sequence until `-taxid` and `-taxid_map` are implemented). Both versions now write the JSON metadata file (`.pjs`, `.njs`). Added `-logfile` (the log and the messages go to the file, appended) and several input files in one `-in`. `-parse_seqids`, `-hash_index`, `-taxid` and `-taxid_map` are still rejected by name. The writer holds the index of a volume once at its close instead of twice: makeblastdb on UniRef50 (38.8 million proteins, five volumes) 303 to 133 MiB peak (NCBI 176 MiB), the files unchanged. The databases are searched as before (`-db` reads versions 4 and 5).
