LOSAT side: BLASTN subject reading/encoding and stats (`algorithm/blastn/input.rs` `read_nucleotide_subjects`, `run.rs`), BLASTP subjects (`algorithm/blastp/blast_engine.rs`), TBLASTN subjects (`algorithm/tblastn/args.rs`, `search_init.rs`, translation, `-lcase_masking`), TBLASTX subjects (`algorithm/tblastx/blast_engine/run_impl.rs`, `translation.rs`; note the approved `-db_gencode` exception). For each NCBI step say where LOSAT must apply the range (cut letters, shift masks, lengths for stats, coordinate shift) and whether existing code then matches NCBI.
