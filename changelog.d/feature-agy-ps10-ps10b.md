- `losat makeprofiledb -binary`: reads PSSM (`PssmWithParameters`) inputs in ASN.1 binary (BER) through the shared table-driven ASN.1 reader (with both ASN.1 text and `-binary` profiles now using `Names::PROFILE`, so `:Type` pointers such as text `:Seq-interval` are refused consistently instead of reporting an erroneous `incompatible member type`), writing the same RPS and protein BLAST database files, messages, exit statuses and `-xmlhelp` output as NCBI BLAST+ 2.17.0 (including multi-volume `-max_smp_vol`, `-index false`, `-blastdb_version 4`, `-scale`/`-threshold`/`-gapopen`/`-gapextend`, `-logfile`, `-dryrun`, non-UTF-8 paths, and `losat rpsblast` parity on `-binary`-built databases). Binary definition lines (`ASN1_BlastDefLine`, `Blast-def-line-set`) now decode through the same shared table-driven BER reader, matching NCBI's serial errors, replaced visible character posts (`803.7`), `NULL` element handling (`NULL` `Seq-id` carried to `FixTaxId` `Attempt to access NULL pointer.`, `-index false` `gnl|BL_ORD_ID` replacement, BER writer `802.5` + `byte N` errors in version 4 and version 5 after a prior profile, and writer-destructor-abort refusal when version 5 has no prior OID), and huge-length handling. Queries whose `iupacna` data holds a byte `>= 0x80` in a pair position (where NCBI's `x_ConvertIupacnaTo4na` indexes its conversion table with a signed `char` and reads before the table) are refused with an explicit message.
