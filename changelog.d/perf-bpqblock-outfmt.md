- `blastp` searches its queries in blocks of whole query batches also when the report is `-outfmt 8`, `9`, `12` (`LOSAT_X_BPQBLOCKSA`) or `5` (`LOSAT_X_BPQBLOCKXML`), as it does for `-outfmt 0`, `6` and `7`: a large query set needs the memory of `-outfmt 6` instead of that of the search of all queries, with the same report bytes. A run whose block search could refuse after some blocks' bytes (an `-outfmt 5` name that NCBI cannot write, a `-db` definition line that does not read or holds a byte outside ' ' to '~') takes the search of all queries. `=0` or `LOSAT_X_DEFAULT=0` turns each off.
