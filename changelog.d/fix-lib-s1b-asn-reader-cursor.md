- The ASN.1 text reader (rpsbproc's BLAST archive input with its Seq-ids, psiblast and tblastn `-in_pssm`, makeblastdb `-mask_data`) keeps its read position in registers while it reads a value, instead of loading it from memory for every byte: rpsbproc's speed on an archive no longer changes with where the program's stack happens to land (dev varied by up to about 2.5 %). Output, errors and refusals do not change.
