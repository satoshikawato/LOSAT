- `blastp` runs the first stage of a search whose report the query blocks do not write (outfmt 10, 18 and 20, `-query_loc`, a custom outfmt 6 or 7 that reads more of a `-db` sequence's titles, and others) in blocks of whole query batches too, each block with its own lookup table, and reports all queries together as before: the output does not change, and the lookup table of all queries is no longer held at once. With `-word_size 4` on 143 bacterial proteins (48,040 letters) against a four-proteome database at one thread, peak memory falls from 267 MB to 92 MB (the time of the `-outfmt 6` search in blocks, a little above the one table's); on 595 proteins from 948 MB to 111 MB. `LOSAT_X_BPQBLOCK=0` keeps one table for all queries ([`docs/agents/diagnostics.md`](docs/agents/diagnostics.md)).
