- `losat psiblast` writes `-outfmt 13` and `14` (one JSON or XML2 file per query, with `-out`), `15` and `16` (the JSON and XML2 documents) with the bytes of NCBI BLAST+ 2.17.0 `-num_threads 1` (apart from the version line, which names LOSAT), at every thread count, for a FASTA query at any `-num_iterations` (convergence included), for `-in_pssm` and for `-in_msa`, with `-db` and `-subject`. Each query's report holds all of its rounds, as NCBI's does: one `Iteration` per round against a database, one `Search` per round with `-subject`, each round's list cut to `-max_target_seqs` as NCBI cuts it. As in NCBI, the report of a FASTA query against a database is made after the query's rounds, when the query has left NCBI's scope: it names the query by its id without a title, and each alignment has its scores without its rows. With `-phi_pattern` (round 1), `13` to `16` write PHI-BLAST's results as NCBI does: one report per pattern occurrence with `-db`, one report per query with a `Search` per occurrence with `-subject`, with the pattern in the parameters. Refused (exit status 1, before the search): `-outfmt 13` to `16` with FASTA queries and `-db` where the database holds the id of a query (`lcl|Query_1`, or the id that `-parse_deflines` reads), because NCBI then shows that database sequence for the query, and with `-db` and a damaged taxonomy database on the search path whose lookups write messages or fail, because NCBI writes those messages where it makes each held report. Before, `psiblast` refused `-outfmt 13` to `16` ("output format N is not supported by LOSAT's PSIBLAST yet"). Tests: frozen NCBI rows `db.ps15b4.*`.
