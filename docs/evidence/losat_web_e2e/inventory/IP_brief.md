# Range IP: protein FASTA input (BLASTP query and subject, TBLASTN query)

Files to write: `IP.tsv`, `IP_notes.md`. Scratch: `scratch_IP/`.

NCBI reads protein FASTA through `CBlastFastaInputSource` / `CBlastInput` (`src/algo/blast/blastinput/blast_fasta_input.cpp`, `blast_input.cpp`, `blast_input_aux.cpp` `ReadSequencesToBlast`, `CBlastInputSourceConfig` flags for proteins) and `CFastaReader` (`src/objtools/readers/fasta.cpp`: defline parsing and ID rules, `ParseDefLine`, title warnings such as "Title ends with at least 20 valid amino acid characters"?, `CheckDataLine`, residue validation for proteins (which letters are valid: `*`, `-`, `U`, `O`, `J`, `B`, `Z`, `X`, digits, lowercase; the "Ignoring invalid residues" warning; hyphens/gaps), empty records, comment lines `;`, `>` without ID, lines before the first defline, CR), then the conversion to NCBIstdaa for the search (`blast_setup_cxx.cpp`, `GetSequence`/`CSeqVector` with `eCoding_Ncbi`/`NCBIstdaa`, the sentinel, how `U`, `O`, `J`, `*` map) and the lowercase mask (`-lcase_masking` for TBLASTN query / BLASTP). Also the `Query_N`/`Subject_N` local IDs for empty or blank IDs and how they appear in outfmt 6/7/0.

LOSAT today reads BLASTP and TBLASTN FASTA with `bio::io::fasta` only (`algorithm/blastp/blast_engine.rs` `run`, `algorithm/tblastn/args.rs` `run`) and encodes residues in `algorithm/blastp/encoding.rs` (and TBLASTN's equivalent). The BLASTN/TBLASTX readers (`algorithm/blastn/input.rs`, nucleotide rules) are the model of how LOSAT reproduces or rejects CFastaReader behaviours (session S07+ §E/§M/§N, S08); the protein residue rules must come from `fasta.cpp` and the IUPACaa/NCBIstdaa tables (`src/objects/seq/seqport_util.cpp`, `src/util/sequtil/`). For each FASTA feature (defline forms, ID forms, residue letters, lines, empty records, file names, stdin) give a row: what NCBI does (output and stderr), what LOSAT does, and whether LOSAT can reproduce it (port) or must reject it. Run both binaries on crafted inputs.
