- BLASTX holds much less memory on a long query, and blastx-fast no longer grows with the thread count. EDL933 (5.6 Mb) x AMRProt, ABRicate's call, peak anonymous memory at 1 / 2 / 4 / 8 / 16 threads: 137 / 193 / 242 / 312 / 508 MiB becomes 72 / 103 / 112 / 134 / 176 MiB (NCBI BLAST+ at 8 threads: 124 MiB). Reports do not change. The flat compressed lookup tables are built on vectors kept between builds (`LOSAT_X_BXCLUTPOOL`), and a batch's end makes no word-hash table per frame and no copy of the residues (`LOSAT_X_BXENDMEM`).
