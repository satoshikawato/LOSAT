- blastn now writes BLAST XML, XML2 and JSON (`-outfmt 5`, `13` to `16`) one query batch at a time, as NCBI BLAST+ 2.17.0 does, instead of holding every report until the search ends; so the hit lists and reports of earlier query batches are no longer kept, and the reports do not change. Where LOSAT refuses a title of punctuation alone (on which NCBI crashes), the reports before it now come first: for `-outfmt 5` those of the query batches before, as for the other formats; with `-outfmt 13` to `16` those of the queries before it, which NCBI writes before it crashes, with `-subject` as with `-db` (with `-outfmt 13` and `14` the refused report's file is left empty, as NCBI leaves it). A refused first report writes nothing of the document, except its start on standard output where a warning came before.
