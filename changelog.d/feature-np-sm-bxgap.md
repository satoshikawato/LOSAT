- BLASTX with `-parse_deflines` now stops, as NCBI BLAST+ 2.17.0 does, when the first line of the query file that is not blank or a comment is a `>?N` gap line: `BLAST query error: CFastaReader: Input doesn't start with a defline or comment around line N`, exit status 1, no output. Before, BLASTX read the gap line as the start of a record without a defline and searched it. The same file as `-subject` now stops too (exit status 1, the query reader's text: the subject's own text, NCBI's `BLAST query/options error: Query input doesn't start with a defline or comment`, is a later change for every program). Files that start with a defline, and runs without `-parse_deflines`, do not change.
