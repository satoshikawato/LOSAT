- Standard output of the command line no longer writes the bytes of a failed write later. Before, a failure that passed (`EAGAIN` on a non-blocking standard output, a device that gets space back) left up to 1023 bytes in Rust's line buffer, and they were written at the next write or at the exit, where NCBI BLAST+ 2.17.0 loses them. This covers `dustmasker`, `segmasker`, `windowmasker`, `convert2blastmask`, `blastdbcmd` (`-metadata` too), `makembindex`, `makeprofiledb`, `rpsbproc`, the help and version texts, and `makeblastdb`'s log. That log is now written as NCBI's: each line goes out in one write at its end, and after a failed write the log writes nothing more (line RG, KC-11b-2).
