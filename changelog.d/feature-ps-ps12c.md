- `losat rpstblastn` takes `-use_sw_tback` with composition-based statistics (`-comp_based_stats` 1, the default, 2 and 3): each profile's matches are aligned again with NCBI's Smith-Waterman redo in the windows of each query frame, so the hits, scores, e-values and reports are those of NCBI BLAST+ 2.17.0 `rpstblastn -use_sw_tback`, byte for byte at every thread count, with `-strand plus`, `-searchsp`, the masks and every output format `rpstblastn` writes.
