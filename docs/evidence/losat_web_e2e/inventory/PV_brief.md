# Range PV: BLASTP options layer, task defaults and NCBI's option checks

Files to write: `PV.tsv`, `PV_notes.md`. Scratch: `scratch_PV/`.

Entry points (NCBI): `CBlastOptionsFactory::CreateTask` for blastp, blastp-fast, blastp-short (`src/algo/blast/api/blast_options_handle.cpp`), `CBlastAdvancedProteinOptionsHandle` and `CBlastProteinOptionsHandle` defaults (`src/algo/blast/api/blast_advprot_options.cpp`, `blast_prot_options.cpp`: matrix, gap costs, word size, threshold, window, cutoffs, X-drops, comp-based-stats, SEG, lookup table type (compressed for word size >= 5?), hitlist, evalue, `SetupDefaults`), the arg handlers that override them in `src/algo/blast/blastinput/blast_args.cpp` (`CGenericSearchArgs::ExtractAlgorithmOptions`: `BLAST_GetProteinGapExistenceExtendParams`, `BLAST_GetSuggestedThreshold`, `BLAST_GetSuggestedWindowSize` when `-matrix` is given, word size; `CCompositionBasedStatsArgs::ExtractAlgorithmOptions`: values 0/1/2/3 and D/F/T spellings, unified P, the `-ungapped` + composition error, `-use_sw_tback`; `CFilteringArgs`: `-seg` values -> filter string), `CBlastOptions::Validate` -> `BLAST_ValidateOptions` (`src/algo/blast/core/blast_options.c`: `BlastScoringOptionsValidate` (matrix names, `Blast_KarlinBlkGappedLoadFromTables` / gap pairs table per matrix in `blast_stat.c`, std_matrix_only), `LookupTableOptionsValidate` (word size ranges per program and lookup type, threshold > 0 "Non-zero threshold required"), `BlastInitialWordOptionsValidate`, `BlastExtensionOptionsValidate`, `BlastHitSavingOptionsValidate` (evalue <= 0, hitlist), `BlastEffectiveLengthsOptionsValidate`), the C++ `CBlastOptionsLocal::Validate` checks, the filtering string parse (`BlastFilteringOptionsFromString` in `blast_filter.c`, SEG window/locut/hicut), and `BlastSetup_ScoreBlkInit`/`Blast_ScoreBlkMatrixInit` errors for unknown matrix names. Also the order in which these errors appear, their texts and exit codes (`BLAST query/options error:`, `BLAST options error:`, `BLAST engine error:`), and which values are accepted silently.

LOSAT counterpart: `algorithm/blastp/args.rs` (`resolve`, `ProteinScoringSpec`, lookup type, task handling), `algorithm/blastp/blast_engine.rs` (`validate_requested_blastp_support` and the checks after it), `blastinput/value_parsers.rs`. One row per option x value class (e.g. each matrix name, gap pairs in/out of the table, threshold 0/negative/real, word size 1..8, window 0, comp_based_stats each spelling, seg forms) and per task default. Run both binaries to confirm messages, exit codes and acceptance.
