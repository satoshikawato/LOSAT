- `losat psiblast -save_pssm_after_last_round -out_ascii_pssm FILE` writes the PSSM of the first round as NCBI BLAST+ 2.17.0 writes it, byte for byte: the port of NCBI's PSSM engine (`PSICreatePssmWithDiagnostics` and its stages) builds the matrix from each query's round-1 alignments and the whole unmasked query, and `PrintAsciiPssm` writes it. The file is replaced after each query that has alignments (`-save_each_pssm`: `FILE.1`, `FILE.2`, ...), a run that writes none leaves an existing file alone, a path that cannot be opened is ignored, `-pseudocount` below 0 or `-inclusion_ethresh` 0 or below ends the run with NCBI's options error after the first report, an O of the query is printed as X (the PSSM's query is the search's letters), and a run that stops at an invalid query keeps the PSSM of the query before it. `-save_pssm_after_last_round` or `-save_each_pssm` without a PSSM file is NCBI's option error. An alignment that would go past the last row of the PSSM's multiple alignment (NCBI writes out of bounds) is rejected, and `-out_pssm` (the ASN.1 PSSM) stays rejected (line PS, item PS2; DECISIONS 8).
