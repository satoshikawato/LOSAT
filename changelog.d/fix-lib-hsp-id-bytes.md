- Library API: `HspRecord::query_id` and `subject_id` are now `losat::api::AccVer`, the id's bytes exactly as the tabular reports write them in `qaccver` and `saccver`, also bytes that are not UTF-8 (a title read from a Latin-1 file, for example). They were `Arc<str>`, in which each such byte had become U+FFFD while the reports kept it. `AccVer` gives the bytes (`as_bytes`), the text where it is UTF-8 (`to_str`) and with U+FFFD otherwise (`to_string_lossy`, `Display`, so `format!("{}", hsp.query_id)` still works), equals a `str` or `[u8]` of the same bytes (`hsp.query_id == "seq1"`), and clones without copying, as before. pylosat's `qaccver` and `saccver` columns and `Hsp.query_id` and `subject_id` stay text, with U+FFFD as before (now documented); the reports, the command line and LOSAT Web do not change.
