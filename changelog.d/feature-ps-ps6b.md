- `losat psiblast -in_msa` reads alignments in FASTA (with gaps), PHYLIP, NEXUS, Sequin and MultAlin format as well as Clustal: the format is found from the first lines of the file as NCBI BLAST+ 2.17.0 does, and the rows, the errors for a file that cannot be read and the exit status are NCBI's. The text after a sequence's name is its title (the `# Query:` line, the PSSM file, the messages), with its `[name=value]` modifiers read as NCBI reads them: the same warnings for a modifier it does not know or discourages, the same error for a value it rejects (PS6b; DECISIONS 74 of line PS). What the modifiers set (organism and other BioSource members, molecule type, comments, publications, protein names, strand, topology, secondary accessions) is written with the query in the PSSM file and the search strategy as NCBI writes it, and a query that a modifier makes a nucleotide sequence stops with NCBI's engine error after the PSSM files are written. Where NCBI crashes or reads memory the file does not give (a PHYLIP header of 0 sequences, an empty NEXUS command, FASTA rows of different lengths read past their end, a `secondary-accession` range that runs backwards, a `molecule` modifier of `other`), LOSAT stops with a message that says so.
