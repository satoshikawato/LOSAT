- `losat rpstblastn` and `losat rpsblast` use less memory with many threads on large profile databases: 100 query records of 5 kb against the CDD database peak at 356 MB with 32 threads instead of 641 MB (44 % lower; 255 instead of 396 MB at 16 threads, 245 instead of 312 MB at 8), and each added thread costs about 4.6 MB instead of 13.7 MB. The output is the same as NCBI BLAST+ 2.17.0's, byte for byte, at every thread count, apart from the version line, which names LOSAT (line PS, series PR, item PS12m; DECISIONS 64 and 65).
