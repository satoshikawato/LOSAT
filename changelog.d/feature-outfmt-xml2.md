- `-outfmt 15` (single-file BLAST JSON) and `-outfmt 16` (single-file BLAST XML2) in `blastp` and `blastn` (all tasks), with `-subject` and `-db`: the `CBlastOutput2` documents that NCBI BLAST+ 2.17.0 writes, byte for byte at every thread count (one report per query, the `Subject_N` list, the query masks, lower-case masked letters (BLASTN: DUST and `-lcase_masking` regions, which BLAST XML does not show), the strands of a BLASTN hit, the `-db` taxid, the one-query delay of a `-subject` search). When `taxdb.bti` is on the search path (the current directory, `BLASTDB`, `.ncbirc`), the scientific name of a `-db` taxid is written after it (`sciname`) as NCBI does; a taxid the taxonomy database does not know, or a damaged one, leaves the `HitDescr` with the id alone, and the reader's messages go to standard error as NCBI's do. A byte outside US-ASCII in a title, in the `-db` name or in a scientific name, which LOSAT cannot write as NCBI does, is refused. Outfmt 0/5/6/7 are unchanged.
