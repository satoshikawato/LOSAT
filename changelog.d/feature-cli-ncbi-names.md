- CLI: the database writer is `losat makeblastdb` (the name `makedb` is gone, `losat makedb` is an unknown command); `-version` (NCBI's two lines, read anywhere before `--` as NCBI reads it) and `-h` (short usage) work for blastn, blastp, blastx, tblastn, tblastx, psiblast and makeblastdb; `-mt_mode 0|1|2` (needs `-num_threads`) is accepted by blastn, blastp, blastx and tblastn with no effect on the output; blastn accepts `-use_index false` (`true` stays an error).
