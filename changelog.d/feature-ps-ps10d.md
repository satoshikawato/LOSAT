- `losat makeprofiledb`: a profile whose query is written in a nucleotide coding (`iupacna`, `ncbi2na` or `ncbi4na`, as a PSSM file may hold it) builds the database that NCBI's makeprofiledb builds, byte for byte, with NCBI's `ib=..,n4sz=..` lines on the standard output when the data is longer or shorter than the query's length, and with NCBI's `Unknown conversion.` error (exit status 255, after the files NCBI leaves) in a profile with frequency ratios only. Data shorter than NCBI reads for the length, where NCBI's makeprofiledb reads past it or crashes, is refused with a message.
