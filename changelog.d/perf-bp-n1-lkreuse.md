- `blastp` at one thread holds less memory when its queries are searched in blocks (more than 50,000 query letters): each block's lookup table is built on the vectors of the block before, grown in place where short, instead of being allocated and freed per block, which left free space in the main heap (peak anonymous memory of 3,000 human proteins against yeast at one thread 25.1 -> 17.6-18.6 MiB) (`LOSAT_X_BPLKREUSE`, a switch of the strict set, so reports do not change; `=0` turns it off) ([`docs/agents/diagnostics.md`](docs/agents/diagnostics.md)).
