- `blastn -task dc-megablast` at two threads or more builds its lookup table for large query sets faster: the pass that places each query word in the table brings in the memory it will write a few words ahead (dmel cDNAs, 31,168 queries, against 3 Mb of the dmel genome: x0.985 of the time at 16 threads, x0.964 at 8 and x0.970 at 4; one thread is unchanged) (`LOSAT_X_DCQSAHEAD`, a switch of the strict set, so reports do not change; `=0` turns it off) ([`docs/agents/diagnostics.md`](docs/agents/diagnostics.md)).
