- `losat rpsblast` and `losat rpstblastn`: a profile database whose profiles have more or fewer consensus letters than score columns (`makeprofiledb` writes one from a scored profile whose sequence is nucleotide-coded or of another length) now opens and is searched as NCBI BLAST+ searches it, with the letters' length in the alignments, e-values and reports. A query batch with a hit on such a profile where NCBI's search would crash or read memory it does not own, or, in `losat rpstblastn` without composition-based statistics, print alignments whose positions and scores disagree, is refused with a message that names the profile.
