- `losat tblastx -strand plus|minus|both` searches the query's frames of the strand it names, as NCBI BLAST+ 2.17.0 does, with `-subject` and `-db` and in every output format: the frames of the other strand take no place in the query (cutoffs, search spaces, masks and frame boundaries are those of the searched frames), the average query length of sum-statistics linking still counts the six contexts of each query, the archive (outfmt 11) and `-export_search_strategy` keep NCBI's search space of context 0 (0 with `minus` unless `-searchsp` is given), and the subject is searched in all six frames. `-strand` is no longer refused; LOSAT Web shows the option under "Query strand".
- `losat tblastx`, every strand: with `-searchsp`, a first query of fewer than 3 nt gives the archive (outfmt 11) the option's search space, as NCBI does (LOSAT wrote 0); a query batch whose average query length is 0 (queries of a few nt, or one strand of short queries) links HSPs with NCBI's cutoffs (LOSAT counted an average of 1).
