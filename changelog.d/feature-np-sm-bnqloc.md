- BLASTN with `-lcase_masking` and `-query_loc` now masks a split query's chunks as NCBI BLAST+ 2.17.0 does: the lower-case runs come from the whole query record, so a run that ends on the nucleotide just before the interval also masks the interval's first nucleotide in the preliminary search of the chunk that starts the query. Before, BLASTN used only the runs inside the interval and could report a hit that NCBI does not report (with `-soft_masking false`, or with the default soft masking when that nucleotide held the hit's only seed). NCBI splits a query batch whose searched nucleotides total 1,999,800 or more with `-task blastn` and `blastn-short`, 9,999,800 or more with megablast and dc-megablast, or as `CHUNK_SIZE` sets. Runs without `-query_loc`, without `-lcase_masking`, with `-window_masker_db`, or whose query batch is not split did not change.
