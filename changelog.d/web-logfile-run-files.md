- LOSAT Web (`web/adapter`, the `losat` npm package, and the browser application) now reads `-logfile` against the run's real files (the run directory and a search's `-query`, `-subject`, `-conffile` and `-window_masker_db` inputs), as the command line does in a folder holding those files: a `-logfile` in a missing folder or naming a folder keeps messages on stderr with no file, a `-logfile` naming an existing file of the run's directory is refused, `windowmasker -logfile /dev/stdout` writes diagnostic messages into stdout in the command line's byte order, and output and log files delivered to the host carry the command line's normalized file name (`run.log` for ` run.log` and `./run.log`, `logs` for `logs/`, `x.counts` for `-out ./x.counts`).
