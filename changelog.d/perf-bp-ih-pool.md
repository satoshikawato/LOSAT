- `blastp` holds less memory with many threads: a subject's array of initial hits starts at NCBI's first size (100) and, past it, continues in arrays shared by all threads instead of each thread keeping the largest array any of its subjects needed (peak anonymous memory of 100 UniRef50 queries against UniRef50 at 32 threads 183-189 -> 158-162 MiB; one thread and time unchanged) (`LOSAT_X_BPIHPOOL`, a switch of the strict set, so reports do not change; `=0` turns it off) ([`docs/agents/diagnostics.md`](docs/agents/diagnostics.md)).
