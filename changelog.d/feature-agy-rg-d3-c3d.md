- `SERIAL_VERIFY_DATA_READ` and `SERIAL_VERIFY_DATA_GET` set to `NO`, `NEVER`, `DEFVALUE` or `DEFVALUE_ALWAYS` (any case) are now honored across every program that reads ASN.1/XML objects or BLAST database definition lines (`psiblast`/`tblastn` `-in_pssm` including feature-table annotation index getters, `makeprofiledb` text/`-binary` profiles and `ASN1_BlastDefLine`, `makeblastdb` `-mask_data` and `-input_type blastdb`, all search programs, `blastdbcmd`, `blastdbcheck`, `dustmasker`, `segmasker`, `windowmasker`, and `makembindex`): well-formed inputs run unchanged, and inputs that fail the disabled read/get check are refused at NCBI's default stop point after the same stdout prefix. Also fixes `seqdb::header::holds_a_seqid` so a definition line lacking its mandatory `seqid` member or with out-of-order members reaches NCBI's normal read error instead of being silently dropped.
