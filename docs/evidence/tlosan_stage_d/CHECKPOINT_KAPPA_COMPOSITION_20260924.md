# TBLASTN Stage D checkpoint: Kappa mode 2 composition inputs and matrices

Branch `feature/tlosan-tblastn-v0.2.0`, following translated-window checkpoint `eab4edd029676621d322d228a0f0958c272b1f4c`. Pinned NCBI C/C++ source: `598d8ae6a72b923127ba2fbfaffd48e4c83bfbf4`. This is **partial Stage D evidence**, not D or E acceptance.

The comparison-only [composition probe](ncbi_kappa_composition_trace.c) and [runner](run_ncbi_kappa_composition_trace.py) saved every `Blast_AdjustScores` call for the code-1 hard-SEG and multi-query local `-subject` mode-2 fixtures. The runner checks the pinned source/executable hash, matches unprobed stdout to the prior fixture, and proves ordinary stderr unchanged by the probe. [Saved calls, probabilities, matrix inputs and all adjusted matrix cells](kappa_composition_matrix_scores_20260924) include one hard-SEG and 20 multi-query calls. NCBI is an oracle only and is not linked or invoked by LOSAT runtime or build.

NCBI `composition_adjustment/redo_alignment.c:906-938` computes translated-subject composition over an HSP-centered range. `composition_adjustment/composition_adjustment.c:61,1204-1248` extends that range toward the nearest stop codons with a strict 20-residue margin. The Rust `blast_get_composition_range` and `translated_subject_composition` ports reproduce **all 28 probability bits and the true-amino-acid count** for the first hard-SEG and multi-query redo inputs. The remaining inputs are taken directly from the pinned call-state trace to isolate the adjustment function.

A first comparison with an approximate test λ of `0.3176/32` produced a λ-ratio difference on multi-query call 1: Rust `0.9789887781985915`, NCBI `0.9789704143789218`. The matrix probe established NCBI's actual scaled `ungappedLambda` as `0.0099251861761165822`, from `blast_kappa.c:2229-2236`. With that exact input and the recorded composition arrays, the Rust `blast_adjust_scores` function matches NCBI's rule, λ-ratio bits, and **all 784 adjusted integer score cells for each of 21 calls**. The first three sampled NCBI start-matrix cells and dimensions are also checked before comparison. This is function-level parity for those input states, not a Rust-generated end-to-end Kappa result. The [focused test](../../../LOSAT/src/core/composition_adjustment/adjust_scores.rs) uses the saved input rows and score matrices. Validation is in [VALIDATION_KAPPA_COMPOSITION_20260924.txt](VALIDATION_KAPPA_COMPOSITION_20260924.txt).
