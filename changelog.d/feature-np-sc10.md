- `tblastx -word_size 2` and `4` (NCBI BLAST+ 2.17.0 takes 2 to 4; LOSAT refused every word size but 3), with every `-matrix`, `-threshold` and `-window_size`, `-subject` and `-db`: the search builds NCBI's lookup table of that word length and runs the reference frame loop and the reference two-hit extension, whose loop over the word reads the length. Output equals NCBI's at 1, 4 and 8 threads. The default search (BLOSUM62, word size 3) runs the code it ran before: instructions at one thread x1.00000 and wall time at 8 threads x0.996 to x0.999 of dev's. Word sizes 2 and 4 run on the reference paths: on a pair of 0.6 Mb genomes at one thread, LOSAT takes 0.11 of NCBI's time (0.06 at word size 3); faster paths for them are a follow-up. The LOSAT Web form offers NCBI's TBLASTX word sizes 2 and 3 (4 after "Other").
