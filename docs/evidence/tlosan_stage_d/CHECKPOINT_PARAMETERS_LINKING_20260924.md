## Remaining gate

On the saved composition-mode-2 local path, the next unported Stage D function boundary is translated-subject Kappa redo. A test-only C→preliminary link→reap path now exists for two fixtures, but the public Rust TBLASTN pipeline remains gated. `redo_alignment.rs` explicitly rejects `subject_is_translated`, while pinned `blast_kappa.c:2423-2478` sets it for TBLASTN and enables `do_link_hsps` with sum statistics. The existing BLASTP path cannot be treated as a TBLASTN result. Port and compare the composition-mode-2 range/translation callbacks, alignment redo, adjusted scores, containment, identity, raw and bit scores, final E-values, heap rank and deletion order using the saved D call order; cover code 32 with the comparison-only NCBI C++ API `FindGeneticCode(32)`.

Only after **all** C and D fixture outputs match may Stage E compare local `-subject` outfmt 0/6/7 byte-for-byte. NCBI `-db` statistics or headers cannot serve as that oracle. Keep the public CLI unimplemented error until all three formats are complete. No D pass, E pass, TBLASTN completion, certification, or performance claim is made here.
