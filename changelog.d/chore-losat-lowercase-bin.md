- The command is now `losat` (`losat.exe` on Windows, `losat.wasm` for the WASI command builds; `target/release/losat`), and the usage and help lines show `losat`. Scripts that call `LOSAT` must change to `losat`; there is no `LOSAT` alias, because the default file systems of macOS and Windows ignore case and cannot hold both names. The Cargo package, the library crate (`LOSAT`, `use LOSAT::...`), the product name in messages and the `LOSAT_*` environment variables are unchanged.
