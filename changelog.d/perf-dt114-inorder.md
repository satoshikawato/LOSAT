- blastdbcmd: printing every sequence of a database (`-entry all`) takes much less time with the same output: the small reads of each sequence (its offsets, header and letters) now come from a few 16 KiB windows of each file that the walk keeps, instead of one system call each. On 300,000 human proteins, `-outfmt "%a %l %T"` takes 55 % less time and FASTA output 54 % less; on 150,000 human cDNAs, `-outfmt "%a %l %T"` takes 65 % less and FASTA output 43 % less. The windows take at most 128 KiB of memory.
