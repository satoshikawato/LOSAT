- `losat makeprofiledb -binary`: reads PSSM (`PssmWithParameters`) inputs in ASN.1 binary (BER) through the shared table-driven ASN.1 reader, writing the same RPS and protein BLAST database files, messages, exit statuses and `-xmlhelp` output as NCBI BLAST+ 2.17.0 (including multi-volume `-max_smp_vol`, `-index false`, `-blastdb_version 4`, `-scale`/`-threshold`/`-gapopen`/`-gapextend`, `-logfile`, `-dryrun`, non-UTF-8 paths, and `losat rpsblast` parity on `-binary`-built databases). Binary definition lines (`ASN1_BlastDefLine`, `Blast-def-line-set`) now decode through the same shared table-driven BER reader, matching NCBI's serial errors, replaced visible character posts (`803.7`), `NULL` element handling, and huge-length handling. Queries whose `iupacna` data holds a byte `>= 0x80` in a pair position (where NCBI's `x_ConvertIupacnaTo4na` indexes its conversion table with a signed `char` and reads before the table) and binary definition lines with a `NULL` `Seq-id` element (where NCBI's version 5 writer aborts) are refused with an explicit message.
