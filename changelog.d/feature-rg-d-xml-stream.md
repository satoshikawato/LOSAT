- blastn now writes BLAST XML, XML2 and JSON (`-outfmt 5`, `13` to `16`) one query batch at a time, as NCBI BLAST+ 2.17.0 does, instead of holding every report until the search ends; so the memory of such a search no longer grows with the number of queries, and the reports do not change. Where LOSAT refuses a title in a later query batch (a title of punctuation alone, on which NCBI crashes), the output of the batches before now comes first, as for the other formats.
