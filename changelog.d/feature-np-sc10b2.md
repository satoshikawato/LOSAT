- `tblastx -word_size 2`, with every `-matrix`: the search takes the unit path of word size 3 (the lookup tables of the query-context groups built directly, and the seed stage of one subject split over the threads by subject frame, chunk and context group) instead of the reference frame loop, which searched a subject on one thread; output unchanged at 1, 4 and 8 threads. On 150 kb slices of AP027131 and AP027133, word size 2 runs 0.738 of the instructions at 1 thread (PAM30 0.650), and at 8 threads takes about 0.11 of the time (PAM30 0.15; a rough measure on WSL). Word size 4 keeps the reference frame loop (its 20-bit table index is outside the 16-bit group builder). The default search (BLOSUM62, word size 3) runs the same machine code, and the other matrices at word size 3 the same instructions.
