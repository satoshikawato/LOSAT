# LOSAT v0.2.0 Release Notes

**LOSAT v0.2.0** expands LOSAT into a 14-program pure-Rust local BLAST+ suite covering all five core search programs (`blastn`, `blastp`, `blastx`, `tblastn`, `tblastx`), PSI-BLAST (`psiblast`), Conserved Domain search and annotation (`rpsblast`, `rpstblastn`, `rpsbproc`), database tools (`makeblastdb`, `blastdbcmd`), and sequence masking (`dustmasker`, `segmasker`, `convert2blastmask`) — all from a single dependency-free static binary, alongside native Rust, Python (`pylosat`), and WebAssembly (`@losat/losat`) library interfaces.

---

## Highlights since v0.1.0

- **New programs & tasks:**
  - `psiblast` (multi-round PSSM iteration, `-in_pssm`, `-out_pssm`, `-out_ascii_pssm`, `-save_pssm_after_last_round`), `rpsblast`, and `rpstblastn` with composition-based statistics (`-comp_based_stats` `0`–`3`, default `1`) matching single-threaded NCBI BLAST+ `2.17.0` bytes.
  - `rpsbproc` (`0.5.1`-compatible CDD domain/site/motif annotation from ASN.1 archive / BlastOutput XML).
  - `dustmasker`, `segmasker`, `convert2blastmask` (with `makeblastdb -mask_data` soft/hard database masking support), `blastdbcmd`, and `tblastn -in_pssm` / genetic code `32`.
- **Complete output formats (`blastn`..`tblastx`):** Supports `-outfmt` `0`–`18` and `20` (Pairwise, Query-anchored `1`–`4`, BLAST XML `5`, Tabular/CSV `6`/`7`/`10`/`20`, ASN.1 text/binary/XML `8`/`9`/`11`, Seqalign JSON `12`, multi-/single-file JSON/XML2 `13`–`16`, SAM `17` for `blastn`, Organism Report `18`).
- **Streamlined inputs:** Transparent reading of `.gz`, `.bz2`, and `.zst` FASTA inputs (in addition to stdin `-query -`).
- **Dramatic performance & memory improvements over v0.1.0:**
  - `blastn` (`31,168` cDNAs vs `3 Mb` chr. 2L, `16` threads): `212.38 s` / `3,858 MiB` → **`4.67 s`** / **`76.6 MiB`** (`45.5×` faster, `50×` less memory).
  - `megablast` (`16S rRNA`, `16` threads): `57.66 s` / `2,031 MiB` → **`4.20 s`** / **`62.0 MiB`** (`13.7×` faster, `32.8×` less memory).
  - `tblastx` (pairwise *Candidatus* genomes, `16` threads): `188.02 s` / `1,605 MiB` → **`4.72 s`** / **`567.5 MiB`** (`39.8×` faster vs v0.1.0, **`629×`** faster than NCBI BLAST+ `2.17.0`'s `2,970.75 s`).
- **Multi-database scaling (`16` threads):**
  - `core_nt` (`319.4 GB`, `132.3M` seqs): **`391.74 s`** warm vs NCBI `542.14 s` (`1.4×` faster) using **`407 MiB`** peak RSS vs **`263,594 MiB`** (**`647×` less memory**).
  - `ref_prok_rep_genomes` (`26.8 GB`, `1.14M` seqs): **`29.37 s`** warm vs NCBI `47.28 s` (`1.6×` faster) using **`358 MiB`** vs **`25,580 MiB`** (**`71×` less memory**).
- **Drop-in pipeline speedups (`--install-shims`):** `1.8×`–`20×` faster BLAST stages inside `AMRFinderPlus` (`20×`), `nf-core/blast` (`14×` / `10×`), `Galaxy` (`12×`), `MAKER` (`11×`), `mlst` (`8.1×`), `ResFinder / PlasmidFinder` (`7.2×`), `BRIG` (`5.6×`), `Prokka`, `Roary`, and `OrthoFinder` with byte-identical outputs.

## Distribution & Package Channels

- **Available with v0.2.0:** Pre-built binaries on [GitHub Releases](https://github.com/satoshikawato/LOSAT/releases/tag/v0.2.0) and packages on [Bioconda](https://anaconda.org/bioconda/losat) (`conda install -c bioconda -c conda-forge losat`).
- **Immediately after v0.2.0:** `losat` on [crates.io](https://crates.io/crates/losat) (with docs on docs.rs) and `pylosat` on [PyPI](https://pypi.org/project/pylosat/) (Arrow/Polars zero-copy Python bindings) will be published as follow-up package releases.
