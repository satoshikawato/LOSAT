# Range NA: TBLASTN application and argument layer

Files to write: `NA.tsv`, `NA_notes.md`. Scratch: `scratch_NA/`.

Entry points (NCBI): `src/app/blast/tblastn_app.cpp` (`CTblastnApp::Run`), `src/algo/blast/blastinput/tblastn_args.cpp` (`CTblastnAppArgs`: arg classes and order, tasks tblastn/tblastn-fast, PSI-TBLASTN), `src/algo/blast/blastinput/blast_args.cpp` (the classes tblastn uses: CGenericSearchArgs, CFilteringArgs (`-seg`, `-lcase_masking`, `-soft_masking`), CWindowSizeArg, CWordThresholdArg, CMatrixNameArg, CCompositionBasedStatsArgs, CGappedArgs, CLargestIntronSizeArgs (`-max_intron_length`), CGeneticCodeArgs (`-db_gencode`), CGapTriggerArgs?, `-xdrop_gap`, `-xdrop_gap_final`, `-sum_stats` (which class), CHspFilteringArgs, CFormattingArgs, CMTArgs, CStdCmdLineArgs, CBlastDatabaseArgs, CRemoteArgs, CDebugArgs, CPsiBlastArgs; `SetOptions` order and `Validate`), `src/app/blast/blast_app_util.{hpp,cpp}`, `src/corelib/ncbiargs.cpp`, `src/corelib/ncbistr.cpp`.

LOSAT counterpart: `cli.rs` (`is_unported_tblastn_arg`), `blastinput/value_parsers.rs` (`tblastn_*` parsers), `algorithm/tblastn/args.rs` (`TblastnArgs`, `validate`, `search_settings`, `run`, `run_local`), `main.rs`. Compare with BLASTN's `run` (model).

Cover, per option in the tblastn scope and per NCBI tblastn option outside it (one row each): type and value parsing (hex, signs, `strtod` spellings, inf/nan, booleans for `-sum_stats`/`-soft_masking`), constraints and their error texts and exit codes, defaults (including those that depend on `-task` and `-matrix`), where/when NCBI reads them, and what LOSAT does (LOSAT reads the inputs with `bio` only; `-query -`/stdin is rejected; `-db`, `-in_pssm`, `-remote`, `-subject_loc` are rejected inside `validate`). Then the application flow as for BLASTN's `run` (outfmt parse, missing subject, subject read, query open, `-out` open, warnings, `Validate`, `Query is Empty!`, query batches of 20000 residues, write failures, environment variables incl. `PRE_FETCH_SEQS_LIMIT=abc` (NCBI exit 255) and `CHUNK_SIZE`, `-num_threads`). Run both binaries on representative bad values to compare stdout, stderr and exit codes.
