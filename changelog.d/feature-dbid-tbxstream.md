- tblastx writes the reports of each query batch when it has searched the batch and drops that batch's hit lists, as NCBI prints each batch's result sets in its batch loop and as blastn does, instead of keeping the lists of every batch for one report after the search; so its memory no longer grows with the number of queries. This applies to `-outfmt 0`, 6 and 7 written to standard output or `-out` where no refusal of LOSAT's can come after the first batch (checked before the search: with `-db`, every definition line of the database, also of databases built with `-parse_seqids`, is read once as the reports read it). Reports do not change.
