- `losat psiblast -save_pssm_after_last_round -out_pssm FILE` writes the PSSM of the first round as NCBI BLAST+ 2.17.0 writes it, byte for byte: NCBI's ASN.1 text `PssmWithParameters` with the query (its id, title and letters), the frequency ratios, the scores, the Karlin-Altschul parameters that the PSSM engine's scaling computes and the scoring parameters, and with `-out_ascii_pssm` too the other diagnostics (information content, weighted residue frequencies, gapless column weights, sigma, interval sizes, numbers of matching sequences). The file is replaced after each query that has alignments (`-save_each_pssm`: `FILE.1`, `FILE.2`, ...), before the ASCII file of the same query, and the stops of the ASCII PSSM (`-pseudocount` below 0, `-inclusion_ethresh` 0, a query that cannot be searched) apply to it too. An `-out_pssm` file that cannot be written, where NCBI stops after that query's report with a serial-stream error, and, with `-out_pssm`, a query title with a byte outside the visible ASCII range, which NCBI writes as `#` with an error message, are rejected (LOSAT stops at the same place in the first case, before the search in the second). A reader of the ASN.1 text PSSM (`blastinput::pssm_text`, NCBI's `ReadDouble` arithmetic) reads every PSSM LOSAT writes and NCBI's test PSSMs; `-in_pssm` stays rejected until it searches with a PSSM. The library API (and pylosat) refuses `-out_pssm` with the other PSSM file options (line PS, item PS3; DECISIONS 10).
