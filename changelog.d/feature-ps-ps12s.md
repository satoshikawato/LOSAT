- `losat rpstblastn` uses its threads on inputs of many short records: several query batches are searched together against each profile volume, and the six frames of each query are searched in parallel, where before only the queries of one 10,000-letter batch did (two workers for records of 5 kb). The volume's files are checked once per run, and the score-only gapped extension of the PSSM searches (`rpstblastn`, `rpsblast`, `psiblast`) is faster. The output is unchanged, byte for byte as NCBI BLAST+ 2.17.0 at every thread count (line PS, series PR, item PS12s; DECISIONS 50).
