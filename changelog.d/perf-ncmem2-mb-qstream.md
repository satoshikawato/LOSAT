- `blastn -task megablast` reads a query file of twice its largest batch or more batch by batch, as the other tasks do (`LOSAT_X_QSTREAM`; until now megablast read every query record before the search), and the second reading of the query file reads the parts of the first on the search's threads where the first was read in parts (two threads or more, a file of 4 MiB or more without `\r` or `>?`), for every task. Outputs do not change. For megablast the store of `LOSAT_X_BNQPACK` and `LOSAT_X_BNQPARTS` now acts only where `LOSAT_X_QSTREAM` does not (a file shorter than twice the largest batch, about 10 MB; `-query -`; `-parse_deflines`; `LOSAT_X_RPTSTREAM` off).
