## Approved Deviation

TBLASTX local `-subject` searches intentionally honor `--db-gencode` for subject
translation/search/reporting for every non-default genetic code. This local
subject genetic-code behavior is approved for v0.1.0 and must not be counted as
a LOSAT parity defect.

No other deviation from NCBI timing, ordering, scoring, filtering, statistics,
pruning, coordinates, or output formatting is approved.

## Verification Commands

Run from the repository root unless noted otherwise.

```bash
cd LOSAT
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-features
cargo build --release
cargo package --list
```

## Release Automation

`.github/workflows/ci.yml` runs the normal PR quality gate: format, clippy,
tests, release build, and serial `wasm32-wasip1` build.

`.github/workflows/release-readiness.yml` is a manual gate for release
candidates. Its default `quality` job records the LOSAT commit, Rust/Cargo
versions, package list, native checksum, serial Wasm checksum, release candidate
artifacts, and release-artifact checksums. Optional manual inputs run native
NCBI oracle diagnostics and Wasm parity diagnostics. Those jobs install NCBI
BLAST+ only inside the validation workflow; LOSAT runtime/build/product code
does not depend on NCBI executables or libraries.

## Contributor And Security Policy

`CONTRIBUTING.md` documents the release-candidate contribution rules: NCBI BLAST
C/C++ source is the behavioral authority, behavior changes need NCBI source
references and parity evidence, unsupported behavior must fail explicitly, and
generated comparison output must not be committed as release source.

`SECURITY.md` documents the pre-v0.1.0 support window, vulnerability reporting
route, and the requirement that security fixes must not add NCBI BLAST+
executables, libraries, bindings, or subprocesses as runtime/build/fallback
dependencies.

`RELEASE.md` is the root-level release entry point and points maintainers to the
v0.1.0 readiness plan, release note, final local gate, required NCBI parity gate,
artifact gate, and publish commands.
