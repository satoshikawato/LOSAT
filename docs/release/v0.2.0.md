## What v0.2.0 provides

One executable, `losat`, with NCBI BLAST+ 2.17.0's command lines (`losat blastn ...`, or `blastn ...`
through the links of `losat --install-shims`):

| Kind | Programs |
| --- | --- |
| Search | `blastn` (`megablast`, `blastn`, `dc-megablast`, `blastn-short`), `blastp` (`blastp`, `blastp-fast`, `blastp-short`), `blastx` (`blastx`, `blastx-fast`), `tblastn` (`tblastn`, `tblastn-fast`, PSSM queries with `-in_pssm`), `tblastx`, `psiblast`, `rpsblast`, `rpstblastn` |
| Databases and masks | `makeblastdb`, `blastdbcmd`, `dustmasker`, `segmasker`, `convert2blastmask` |
| Domain annotation | `rpsbproc` |

The search programs read BLAST databases (`-db`) and, except `rpsblast` and `rpstblastn` (as in
NCBI), FASTA subjects (`-subject`); each can read its query from the standard input (`-query -`).
The options, output formats and the cases LOSAT refuses are listed per program in README.md,
[Scope & Differences from NCBI BLAST+](../../README.md#scope--differences-from-ncbi-blast).

## Differences from NCBI BLAST+ 2.17.0 that ship with v0.2.0

Each difference has a product decision:

- [PD-TBLASTX-LOCAL-SUBJECT-GENCODE](../product_decisions/PD-TBLASTX-LOCAL-SUBJECT-GENCODE.md) and
  [PD-TLOSAN-LOCAL-GENCODE-32](../product_decisions/PD-TLOSAN-LOCAL-GENCODE-32.md): a local
  `-subject` search of `tblastx` and `tblastn` translates the subject with the code `-db_gencode`
  selects, where NCBI's local search uses code 1; `tblastn` also accepts genetic code 32.
- [PD-LOSAT-PLATFORM-LIBM](../product_decisions/PD-LOSAT-PLATFORM-LIBM.md): on macOS, the last
  (15th) digit of a full-precision E value (`-outfmt 11`, `-outfmt 8`) can differ by 1; on WASI,
  the last (15th) digit of a value in psiblast's ASN.1 PSSM (`-out_pssm` with `-out_ascii_pssm`)
  can differ by 1, as in NCBI BLAST+ on an x86-64 CPU without FMA (Owner, 2026-11-18).
- [PD-NCBI-PLATFORM-VARIANCE](../product_decisions/PD-NCBI-PLATFORM-VARIANCE.md): in the six
  cases run with NCBI on Windows, macOS and Linux aarch64, NCBI's builds for those platforms may
  differ from its Linux x64 build within the bounds recorded there; LOSAT's output is checked against
  the Linux x64 bytes on every platform.
- [PD-LOSAT-NCBI-DEFECTS](../product_decisions/PD-LOSAT-NCBI-DEFECTS.md): where NCBI's result
  depends on undefined behaviour (a signed overflow, a read outside its buffers), LOSAT computes the
  value without it or refuses the input; each case is listed there.
- [PD-LOSAT-CLI-NONSEARCH-DIFFERENCES](../product_decisions/PD-LOSAT-CLI-NONSEARCH-DIFFERENCES.md),
  [PD-LOSAT-DATABASE-SEARCH](../product_decisions/PD-LOSAT-DATABASE-SEARCH.md),
  [PD-LOSAT-BLASTDBCMD-DEVIATIONS](../product_decisions/PD-LOSAT-BLASTDBCMD-DEVIATIONS.md) and
  [PD-LOSAT-ARCHIVE-DEFLINE](../product_decisions/PD-LOSAT-ARCHIVE-DEFLINE.md).

The `LOSAT_X_*` variables, `LOSAT_TIMING`, `LOSAT_X_STATS`, `LOSAT_X_REACH` and
`--features diagnostics` are development settings outside the release's claims.

## Not in v0.2.0

- On the list for a later release (Owner, 2026-11-17): `deltablast`, `makeprofiledb`,
  `psiblast -in_msa` (with `-msa_master_idx` and `-ignore_msa_master`) and `-phi_pattern`, the
  `psiblast` output formats other than `0`, `6`, `7`, `10` and `20` (with `-in_pssm`: `0`, `6`,
  `7`), the `rpsblast` output formats other than `0`, `6`, `7` and `10` and the `rpstblastn` ones
  other than `0` to `4`, `6`, `7` and `10` (so `rpsbproc` reads the `-outfmt 11` archives written by
  NCBI's `rpsblast` and `rpstblastn`), `blast_formatter`, `windowmasker` and `-html`.
- Programs not provided: `blastdb_aliastool`, `blast_formatter_vdb`, `blast_vdb_cmd`, `blastn_vdb`,
  `tblastn_vdb`, `blastdbcheck`, `makembindex`, `legacy_blast.pl`, `update_blastdb.pl`,
  `get_species_taxids.sh`, `cleanup-blastdb-volumes.py`.
- Options that need NCBI's servers or its GI and IPG databases: `-remote` and `-entrez_query` (all
  programs), `-gilist` and `-negative_gilist`, `-ipglist` and `-negative_ipglist`;
  `-import_search_strategy` is refused.
