The first demonstrated upstream discrepancy is the initial ungapped X-drop, before HSP sorting or final traceback. The public C++ options path allocates zeroed initial-word options (`blast_options_local_priv.cpp:49–54`). Traditional megablast calls `SetMBInitialWordOptionsDefaults`, which sets only its window (`blast_nucl_options.cpp:115–133,171–174`). Ordinary blastn sets the 20-bit X-drop (`163–168`); discontiguous megablast also explicitly sets it (`disc_nucl_options.cpp:66–73`). The C option constructor is a different path and cannot substitute for these C++ defaults.

`blast_parameters.c:218–221,380–383` converts the initial bit value and, when it is zero, uses the subject-specific cutoff as the actual raw X-drop. The isolated NCBI diagnostic records zero initial bits, zero initial raw score, and raw X-drop 13 in both NZ query contexts. B0 supplied 20 bits, producing raw 11.

B0's later interval supplies 320736 / 321989 and keeps 320677 / 321930. The preliminary endpoints and score coincide, so examining final HSP keys alone hid the upstream difference. Final traceback then differs in script length (1131 vs 1130), identities, mismatch count and gap count.
