- `losat makeprofiledb`: a profile whose query is written in a nucleotide coding (`iupacna`, `ncbi2na` or `ncbi4na`, as a PSSM file may hold it) builds the database that NCBI's makeprofiledb builds, byte for byte, with NCBI's `ib=..,n4sz=..` lines on the standard output when the query's ncbi4na data, or the ncbi4na form of its iupacna letters, has another byte count than its length needs, and with NCBI's `Unknown conversion.` error (exit status 255, after the files NCBI leaves) in a profile with frequency ratios only. In such a profile a query in another coding also gets NCBI's result: the same error for `ncbi8na`, the codes of `ncbi8aa`, NCBI's unknown exception for `ncbipna` and `ncbipaa`. Data shorter than NCBI reads for the length, where NCBI's makeprofiledb reads past it or crashes, and a query that is a gap in a profile with frequency ratios only, where it reads past its table of codings, are refused with a message.
