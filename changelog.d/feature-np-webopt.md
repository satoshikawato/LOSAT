- LOSAT Web accepts `-num_descriptions` and `-num_alignments` in BLASTN, BLASTP, TBLASTN and TBLASTX (the form lists them under "Other Parameters" as "Number of descriptions" and "Number of alignments"; `describe` lists them with the CLI's help). A Web run searches once for each distinct hit list size of its formats (NCBI `blast_args.cpp:2894-2973`), the tabular formats first: one search as before, or two when the options give outfmt 0 another hit list size than outfmt 6 and 7 (for example `-num_alignments 10`), at about twice the time and the memory of the larger search. Each stream is the native CLI's output for that format alone; the HSP records, the results screen and the diagnostics (stream 3, the CLI's standard error for outfmt 6) follow the tabular formats, and a record gets its outfmt 0 section only where the outfmt 0 search found exactly the same HSPs. `-num_alignments 0` does not fail the run: outfmt 0 is written and the tabular formats carry NCBI's `No hits are being saved` error on stream 3, without HSP records. ABI v2 keeps its version (docs/web/abi_v2.md §5, §7, §8). New frozen NCBI fixtures `numdesc.blastn.split_na3` (and `.6`): the one input where a smaller hit list keeps other subjects than the head of a larger one.
