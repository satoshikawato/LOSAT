- tblastx keeps each query's hit list (`-max_target_seqs` subjects, default 500) inside the search of a query batch, as NCBI's HSP collector does, instead of keeping every HSP of every query and subject of the run until the last report ordered them. A `-db` search of many queries against a database that every query hits held about 190 bytes per uncapped HSP for the whole run: 50 of the records of `18S_fungal_sequences` against that database used 3.7 GB (NCBI BLAST+ 2.17.0: 0.43 GB). Reports do not change; `-culling_limit` keeps its culling at the end of each batch.
