- `-window_masker_taxid` in BLASTN (NCBI BLAST+ 2.17.0 `blast_args.cpp:430-466`, `winmask_filter.cpp:371-428`): the masks of WindowMasker from `<directory>/<taxid>/wmasker.obinary`, with the four tasks, `-subject` and `-db`, `-strand`, split query batches and every output format (BLAST XML's filter `W -t <taxid>;`, the archive's `WindowMaskerTaxId`, which the taxid 0 leaves out). The directory is NCBI's: `NCBI_CONFIG__WINDOW_MASKER__WINDOW_MASKER_PATH`, then `WINDOW_MASKER_PATH`, then `[WINDOW_MASKER] WINDOW_MASKER_PATH` of the first `.ncbirc` (also when the program's `.ini` turns `.ncbirc` off), then the current directory; an empty value is the current directory. The taxid 0 uses no WindowMasker. A taxid without a counts file, or with one NCBI cannot read, stops each query batch with NCBI's error (exit 3); `-window_masker_taxid` with `-window_masker_db` (the taxid 0 too) is NCBI's input error (exit 1) after the check of the `-window_masker_db` file. LOSAT refuses a counts file in the ascii or optimized ascii format there, which NCBI reads, before any output.
- `[WINDOW_MASKER] WINDOW_MASKER_PATH` in `.ncbirc` and `NCBI_CONFIG__WINDOW_MASKER__WINDOW_MASKER_PATH` are accepted by every program (they change no output without blastn `-window_masker_taxid`).
- LOSAT Web refuses `-window_masker_taxid` other than 0 (it has no directory of counts files yet).
