- `losat blastp -ungapped` writes NCBI BLAST+ 2.17.0's report of an ungapped alignment of length 0 (reached with `-window_size 0` and a low `-threshold`) in every output format but `-outfmt 1` to `4` (apart from the version line, which names LOSAT): a row of the tabular formats with `qend` one below `qstart` and no letters, an alignment block without rows in `-outfmt 0`, empty strings and an alignment length of 0 in XML and JSON, an alignment of length 0 in `-outfmt 8`, `9`, `11` and `12`. With `-subject` (and `-subject_loc`), NCBI stops with its exception (exit status 255) at such an alignment at the first letter of the searched part of a subject; LOSAT ends the same way, after the same bytes (apart from the version line, which names LOSAT), with NCBI's message in LOSAT's words. `-outfmt 1` to `4` is refused by name where NCBI crashes (the merge of the query-anchored alignments); the other searches are written.
