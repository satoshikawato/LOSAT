- blastdbcmd `-outfmt` with `%` specifiers takes less time with the same output and memory: each field is written into the line where its specifier stands, numbers as digits without Rust's formatting machinery, and the line's buffer is kept from one line to the next. On 300,000 human proteins, `-outfmt "%a %l %T"` takes 16 % less time; on 150,000 human cDNAs, 8 % less. The numbers in Seq-id labels (versions, GIs, numeric `gnl` ids), which every program writes, go the same way.
