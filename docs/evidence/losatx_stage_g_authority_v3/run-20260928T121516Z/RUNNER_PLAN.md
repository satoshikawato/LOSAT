The GitHub API reported zero registered self-hosted runners. The user has now explicitly authorized committing the reviewed candidate, pushing it, and opening a PR. These hosted labels provide a concrete route to real hardware. **No BLASTX M1–M11 search matrix on those labels has been executed in this binding.** Existing macOS release workflows cover the earlier v0.1.0/PR6 contract; their outputs cannot be counted as the BLASTX matrix. Cross compilation and emulation cannot satisfy this gate.

Make the fixture catalog and raw Linux acceptance bytes portable while preserving fixed sequence bytes, relative names, argv, input order, options, and output destinations.
