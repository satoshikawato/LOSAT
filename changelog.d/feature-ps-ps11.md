- `losat rpsblast` searches protein queries against a profile database (`makeprofiledb -dbtype rps`, version 4 or 5, the 28-column profiles of makeprofiledb 2.17 and the 26-column ones of NCBI's older databases, any whole scale such as CDD's 100) byte for byte as NCBI BLAST+ 2.17.0 does without composition-based statistics (`-comp_based_stats 0`, `F`, `f`, `D` or `d`; with any mode when the database has no frequency ratios, as NCBI then runs it, with its two warning lines), for outfmt 0, 6, 7 and 10 (custom tabular fields too), `-evalue`, `-max_target_seqs`, `-num_descriptions`/`-num_alignments`, `-max_hsps`, `-qcov_hsp_perc` (NCBI's coverage of the first query of each query batch), `-window_size` (0: the one-hit word finder), `-query_loc`, `-parse_deflines`, `-show_gis`, and every `-num_threads` and `-mt_mode` (the output is NCBI's `-num_threads 1` output; the queries run in parallel). The search reads the database's prebuilt lookup table (`.loo`) and profiles (`.rps`) through read-only memory maps, scans each query into NCBI's 2,048-row buckets in chunks of 4,000,000 hits, extends the word hits on NCBI's diagonal table of the concatenated profiles (its length, mask and the opposite sign of the one-hit finder, so long queries share diagonals as in NCBI), aligns them on each profile with the database's scale, rescales each hit profile to the query's composition in the traceback (`RPSRescalePssm`) with the profile's K, and prints NCBI's outfmt 0 footers (the gapped K of each query batch's first query). NCBI's errors of a missing or damaged `.aux`, `.loo` or `.rps` file are copied (exit status 3, the canonical path). Refused until item PS11b: composition-based statistics with the database's frequency ratios (the default `-comp_based_stats 1`), databases of several volumes; refused: other output formats, `-seg` other than `no`, `-soft_masking true`, `-lcase_masking`, `-dbsize`, `-searchsp`, `-line_length`, `-html`, `-sorthits`, `-sorthsps`, `-sum_stats`, the X-drop options, `-use_sw_tback`, a database of another matrix or gap costs than BLOSUM62 11/1, an empty or inconsistent `.rps`/`.loo`/`.aux`, the library API and the Web engine (line PS, series PR, item PS11a; DECISIONS 16).
