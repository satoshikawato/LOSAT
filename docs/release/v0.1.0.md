## Approved Deviation

TBLASTX local `-subject` searches intentionally honor `--db-gencode` for subject
translation/search/reporting for every non-default genetic code. This local
subject genetic-code behavior is approved for v0.1.0 and must not be counted as
a LOSAT parity defect.

No other deviation from NCBI timing, ordering, scoring, filtering, statistics,
pruning, coordinates, or output formatting is approved.

## Verification Commands

Run from the repository root unless noted otherwise.

```bash
cd LOSAT
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-features
cargo build --release
cargo package --list
cargo publish --dry-run
```

Native NCBI parity:

```bash
cd LOSAT/tests
bash run_comparison.sh
python3 compare_blastn_parity.py
bash run_blastp_comparison.sh

cd ../..
bash tests/compare_tblastx_native_ncbi_parity.sh
bash tests/compare_self_tblastx.sh
bash tests/compare_long_sequences_debug.sh
```

Wasm validation, if artifacts are shipped:

```bash
cd LOSAT
cargo build --release --target wasm32-wasip1 --no-default-features
cargo build --release --target wasm32-wasip1-threads --features wasm-threads

cd tests
bash run_wasm_comparison.sh
cd ../..
bash tests/compare_tblastx_wasm_parity.sh
```
