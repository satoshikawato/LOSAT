- With `-subject` and `-outfmt` 13, 14, 15 or 16, the five search programs no longer refuse a title that the XML2 or JSON document cannot write when it is in the report that NCBI BLAST+ 2.17.0 holds back and never writes: the report of the last query before a batch that stops the run (a reader error, or a last batch without letters), including the titles of that query's subjects with hits. They give NCBI's result there instead (the reports before it, then the error). The library API of `blastx` now refuses a title that outfmt 5 or these documents cannot write before their first byte, as the command line does (before, after the start of the document or the reports of the batches before it).
