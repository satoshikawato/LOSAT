- `tblastn -db` reads each database sequence where it searches it instead of a copy of the whole database made before the first query batch (24 MiB of anonymous memory for the 100 Mb C. elegans genome, 32 MiB for a zebrafish cDNA set); the composition redo, the traceback and the reports read the sequences they need, into the large translated frames of the subjects already searched (`LOSAT_X_TBNDBSTREAM`, one of the switches of the strict set, so reports do not change; `LOSAT_X_TBNDBSTREAM=0` turns it off; `LOSAT_X_TBNDBSTREAMSHADOW=1` also makes the copy and compares every read with it) ([`docs/agents/diagnostics.md`](docs/agents/diagnostics.md)).
