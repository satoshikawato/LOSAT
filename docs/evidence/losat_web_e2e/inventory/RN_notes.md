## Findings that change output today (divergent rows)
1. `Matrix:` line prints the user's spelling in NCBI (`-matrix blosum62` -> `Matrix: blosum62`); LOSAT upper-cases (TBLASTN). Medium impact, S.
2. TBLASTN Sbjct row, middle line, Positives (outfmt 0) and % identity/mismatches (outfmt 6/7, only when the query letter is B/Z/J) for subjects with IUPAC codes: NCBI re-translates with CTrans_table (B/Z/J/X); LOSAT prints the search translation (X). 14 of 60 random cases with 1% ambiguity differ. TBLASTX and BLASTX already have `display_residue`/`display_codon`. Fix S.
3. Default number of alignments: NCBI shows 500 descriptions but 250 alignments unless `-max_target_seqs` is given; TBLASTN prints 500 alignments (default 500 is indistinguishable from an explicit 500). TBLASTX is right (run_impl.rs:1328-1330). Fix S (make `max_target_seqs` an Option).
4. HSPs of raw score 0 (exist for large `-evalue` because `BLAST_SpougeEtoS` has no lower bound) are never converted to Seq-aligns in NCBI; LOSAT prints them in outfmt 6/7 (zero-length rows, counted in "# N hits found") and aborts outfmt 0 ("TBLASTN report HSP has no edit script"). Onset: -evalue 1e4 for 30-120 aa queries vs 6 kb, 1e6 for ~900 aa vs 210 kb. TBLASTX cannot produce them (BLAST_Cutoffs lower bound 1).
5. Query containing `O`: NCBI replaces it by `X` in the query buffer (blast_setup_cxx.cpp:889-895) and warns; LOSAT keeps code 26, so the ungapped Lambda/K/H footer differs (ROOT CAUSE of the S08 hand-off "35 of 3000 inputs, last digit"). With O replaced by another letter all 3000 queries are identical. Warning text is range IP.
6. TBLASTN epilog threshold is an `i32` (NCBI: double through the stream default format: `11.5`, `1e+06`). Not reachable today (only 13/16 accepted); TBLASTX already has `cpp_default_double`.
7. Query defline `>` / `> text` (outfmt 0/6/7) and control characters / empty subject warning: reader differences (ranges IP/IN), recorded because they are visible in the report.
8. UNSURE: `-comp_based_stats 0` (also BLOSUM45 profile) on an AT-repeat query region: equal-score, equal-coordinate HSPs of different frames; NCBI keeps frame +1 where LOSAT keeps +3 (1 of 336 real queries). Probably a sort-stability or per-frame list-order effect in the non-kappa traceback path; the kappa path (cbs 2) agrees.

## S08 hand-offs resolved
- TBLASTN epilog threshold integer vs `%g`: row "Neighboring words threshold" (divergent, unreachable now).
- Lambda/K/H last digit: letter `O` (see 5).
- `BLAST_Cutoffs` lower bound: `.max(1)` (stage_d_stats.rs:243) is the same as `blast_cutoffs_from_one` (faithful). The lower bound is NOT applied in the Spouge branch used for gapped searches; that is NCBI behaviour and the source of the score-0 HSPs (4).
- `%#8.3g`: reproduced for 60018 values (scratch_RN/kafmt).
- Subject lowercase intervals: TBLASTN already identical (HSP sets and display); TBLASTX lacks the options.
- Punctuation-only titles: rejected in both programs at the base commit; NCBI exits 139 (segfault), approved exception 2 says print the cut title as BLASTN does. The 1023-title sweep (`../title-sweep-before.tsv`) shows 957 identical and 66 punctuation-only titles.
