- BLASTP and PSIBLAST `-db`: a pyrrolysine (O) stored in a protein database is searched as it is stored, as NCBI BLAST+ 2.17.0 does, instead of as X. A query word holding X (or a query O, which is read as X) whose own score is under the word threshold now finds a stored X and no longer a stored O, so the extra hits and the changed alignments that the stored O gave are gone (for example `blastp -comp_based_stats 0` of `IIII...AOA...` against a database holding `VVVV...AOA...`: NCBI and LOSAT now report no hit); PSIBLAST's later iterations and `-in_pssm` score a stored O with the PSSM's own score for O, as NCBI does, not with its score for X.
