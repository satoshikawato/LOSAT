- Every program starts with less work: a run sets up the command-line options of its own program only, not those of all ten programs. That saves 1.8 to 2.0 million instructions per run; a short `blastn` search takes 1.7 million instead of 3.5 million, and `makeblastdb -help` 5.1 million instead of 7.1 million. Memory use is the same or lower, and help texts, errors, exit statuses and reports do not change.
