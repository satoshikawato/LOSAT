- LOSAT Web: an input whose first line is an accession (or a GI number) followed by other text now
  says how to fetch it ("To fetch accessions, put only the accessions in the box, one per line;
  otherwise start the input with a '>' defline.") instead of calling the fetch unsupported in the
  browser. A pasted list of accessions on one line, separated by spaces or commas, which cannot be
  read, has "Put each accession on its own line", which rewrites the box so that Fetch takes them.
  The command line's message is unchanged.
