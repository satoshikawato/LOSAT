- `-export_search_strategy -` writes the search strategy to the standard output as NCBI BLAST+ does, in all eight search programs: each request goes into the report ahead of its batch's results when the report is on the standard output too (after the report's start, also for `psiblast -in_pssm` and `-in_msa` with rounds or `-out_pssm`), and the requests alone are on the standard output with `-out`. LOSAT Web and the library API still refuse `-`.
- A run whose report cannot be written (`-out /dev/full`, a file at its size limit) no longer writes the search strategy requests of the query batches after the one whose report failed: `-export_search_strategy` (a file, `/dev/stdout` or `-`) ends with the requests NCBI BLAST+ 2.17.0 wrote before its run stopped. Before, `blastp`, `tblastn` and the other programs that read several batches ahead added the next batches' requests.
- `-outfmt 20` writes its line of field names where NCBI BLAST+ writes it, in every search program: before the first query batch and its search strategy request, flushed at once. With `-export_search_strategy /dev/stdout` (or `-` with `-out /dev/stdout`) the requests come after that line, and with `2>&1` NCBI's `803.7` posts of a request too; LOSAT's refusals at a query batch or its report follow it on the standard output.
