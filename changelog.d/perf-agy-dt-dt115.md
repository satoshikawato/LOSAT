- blastdbcmd takes less time with the same output: each sequence's definition lines are now decoded into the buffers kept from the previous sequence (lines, titles, Seq-id lists, and Seq-id strings) instead of allocating and freeing a new set per sequence, and title visible-character replacement and counting run in a single 16-byte pass. On 300,000 human proteins, `-outfmt "%a_%l_%T"` takes 11–13 % less time and FASTA output 5–6 % less; on 150,000 human cDNAs, `-outfmt "%a_%l_%T"` takes 8 % less; on NCBI Swiss-Prot and PDBaa, `-outfmt "%a_%l_%T"` takes 7 % and 11 % less time and FASTA output 2–3 % less.
